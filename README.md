---

## ✨ Features & Interactive Modules

This portfolio is packed with rich, highly polished components that are styled with strict design guidelines:

1. **🛠️ Interactive Resume Customizer**
   - Allows prospective recruiters to type their company name and dynamically customize resume bullet points, priorities, or tech stacks to fit their job descriptions.
   - Highlights live state propagation in full print layout previews.

2. **🤖 AI Copilot Workspace Simulator**
   - A fully functional client-side sandbox replicating a developer terminal workspace.
   - Allows users to input system prompt configurations, model temperatures, and simulate raw execution streams to calculate token sizes and exact cost latencies before live deployment.

3. **💬 Blog & Recruiter Feedback Loop**
   - An elegant micro-blogging engine supporting multiple categories (e.g., Tech, AI Developer, Product, DevOps) and full-text searching across titles, tags, and content.
   - Includes an inline recruitment feedback sub-module with custom avatars and state management.

4. **📟 Secure Contact Console & SMTP Proxy Simulation**
   - A dual-pane contact terminal. The left side handles fully validated message collection.
   - The right side features a real-time reactive **Local State Sandbox Terminal** that logs connection payloads and stream parameters as they propagate.

5. **⚡ Tech Stack**

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| Framework | React 19 + TypeScript | Advanced hook cycles, static data management, stable rendering |
| Build Tool | Vite 6 | Hyper-fast module resolution, lightweight production builds |
| Styling | Tailwind CSS v4 | Responsive utility-first layout, mobile touch targets, desktop precision |
| Animation | Motion (Framer Motion) | Stagger animations, modal fade-ins, adaptive transitions |
| Icons | Lucide Icons | Clean vector shapes scaling gracefully across all viewports |

## 🎨 Design System: Cosmic Orange & Slate

- **Primary Background**: `#0A0A0A` (Deep Slate / Obsidian Black)
- **Primary Accent Color**: `#F27D26` (Cosmic Fire Orange)
- **Secondary Neutral Accents**: `#AAAAAA` (Cool Gray) & `#333333` (Industrial Grid Borders)
- **UI Styling Rules**: Sharp zero-radius borders (`rounded-none`), heavy structural card framing, and custom-positioned CSS background mesh-glow elements targeting high visual rhythm. No tech-larping or mock status indicators — human-readable, beautifully structured layouts only.

## 🛠️ Quick Start & Local Setup

Prepare your development environment to run this portfolio locally:

### 1. Install Dependencies
```bash
npm install
```

### 2. Launch Local Dev Server
```bash
npm run dev
```
*The dev server is preconfigured to bind to port `3000` via Host `0.0.0.0` for immediate preview convenience.*

### 3. Generate Optimized Production Assets
```bash
npm run build
```
The compiled, highly optimized static documents will generate cleanly inside the `/dist` directory, fully prepared for deployment to static CDNs or hosts like **Vercel**, **Netlify**, or **GitHub Pages**.
